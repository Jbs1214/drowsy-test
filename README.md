# 졸음운전 감지 테스트

여러 모델로 졸음운전 감지를 테스트하는 저장소다. 모델마다 폴더 하나를 쓰고, 각 폴더는 독립적으로 설치하고 실행한다.

## 폴더

| 폴더 | 모델 | 설명 |
|---|---|---|
| [`mobilevit/`](mobilevit/) | MobileViT v2 ([mosesb/drowsiness-detection-mobileViT-v2](https://huggingface.co/mosesb/drowsiness-detection-mobileViT-v2)) | 웹캠·영상 감지, 모델 2초 평균 판정, 화면·소리 경고 |
| [`mediapipe/`](mediapipe/) | mediapipe Face Landmarker (규칙 기반, 학습 모델 없음) | 웹캠·영상 감지, 눈 감음·하품·고개 끄덕임 규칙, 화면·소리 경고 |

## 실행

각 폴더의 `README.md`를 따른다. 공통 흐름은 아래와 같다.

```bash
git pull
cd <모델 폴더>
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 모델별 비교

### 데이터

- `sleep/` 폴더의 차량 내 운전자 영상 160개(운전자 8명 × 20개, 1280×720, 30fps, 3.7~17.6초, 총 23분)와 라벨(`sleep/TL1/**/label/*.json`). GitHub에는 올리지 않는다.
- 라벨은 영상마다 시나리오 1개(`scene_info.category_name`)다. `졸음운전`을 졸음, 나머지를 졸음 아님으로 보고 평가했다.

  | 라벨 | 영상 | 프레임 라벨의 주요 행동 |
  |---|---|---|
  | 졸음운전 | 80 | 꾸벅꾸벅졸다, 하품, 뺨 때리기·목 만지기 |
  | 음주운전 | 49 | 무언가를 마시다, 몸 못 가누기, 핸들 놓치기·흔들기 |
  | 물건찾기 | 30 | 몸 돌리기, 허리 굽히기, 손 뻗기 |
  | 휴대폰조작 | 1 | 고개 돌리기 |

  - 정상 운전만 있는 영상은 없다. 오경보는 "다른 이상 행동을 졸음으로 착각한 비율"이다.
  - 데이터셋 오류: `TS1/SGA2100304/SGA2100304S0068/` 폴더 안 영상 이름이 `SGA2100304S0069.mp4`다. 폴더 이름대로 `SGA2100304S0068` 라벨(졸음운전)로 평가했다.
- 모든 방식에서 30fps 영상을 3프레임마다 1장씩(10fps) 판정했고, 영상 안에서 한 번이라도 경고가 나면 "경고"로 셌다.

### 결과 (2026-10-29)

| 방식 | 얼굴 검출 | 졸음 감지 (80개 중) | 오경보 (80개 중) | 정확도 | 처리 시간 (CPU) |
|---|---|---|---|---|---|
| 모델만 ([`mobilevit/`](mobilevit/)) | Haar | 33 (41%) | 31 (39%) | 51% | 약 140ms/프레임 |
| 모델 + mediapipe 규칙 | mediapipe | 80 (100%) | 75 (94%) | 53% | 약 150ms/프레임 |
| **mediapipe 규칙만 ([`mediapipe/`](mediapipe/))** | mediapipe | **80 (100%)** | **50 (62%)** | **69%** | 약 20ms/프레임 |

- 모델: MobileViT v2, 얼굴 이미지의 2초 평균 Drowsy 확률 > 0.7이면 경고.
- mediapipe 규칙: 눈 감음 1초 이상, 하품 1초 이상, 고개 끄덕임 15° 이상 중 하나라도 해당하면 경고. 자세한 기준은 [`mediapipe/README.md`](mediapipe/README.md).
- "모델 + mediapipe 규칙"은 커밋 `99c51b2`의 `mobilevit/`에서 측정했다. 지금은 폴더로 남기지 않았다.

라벨별 경고 수:

| 방식 | 졸음운전 (80) | 음주운전 (49) | 물건찾기 (30) | 휴대폰조작 (1) |
|---|---|---|---|---|
| 모델만 | 33 | 23 | 8 | 0 |
| 모델 + mediapipe 규칙 | 80 | 49 | 25 | 1 |
| mediapipe 규칙만 | 80 | 31 | 19 | 0 |

### 해석

- **MobileViT 모델은 졸음과 다른 행동을 구분하지 못한다.** 평균 Drowsy 확률이 졸음운전 0.73, 음주운전 0.83, 물건찾기 0.71이다(mediapipe 얼굴 검출 기준). 모델만 쓴 정확도 51%도 얼굴 검출이 자주 끊겨 경고가 덜 났을 뿐이다.
- 모델에 규칙을 더하면 졸음은 다 잡지만, 모델의 오경보가 그대로 더해져 정확도가 53%다.
- **mediapipe 규칙만 쓸 때 가장 낫다(정확도 69%).** 처리 속도도 7배 빠르다. 다만 오경보 62%는 여전히 높다. 대부분 고개 끄덕임 규칙이 음주운전·물건찾기의 몸 숙임을 졸음으로 판정한 것이다.
- 규칙 기준값을 같은 데이터의 일부 영상을 보고 정했으므로, 규칙 쪽 결과는 실제보다 좋게 나왔을 수 있다.

## 새 모델 폴더 추가 규칙

다른 모델을 테스트할 때는 기존 폴더를 고치지 말고 새 폴더를 만든다.

1. `feat/<모델명>` 브랜치를 만들고, 루트에 `<모델명>/` 폴더를 만든다.
2. 폴더 안에 아래 파일을 둔다.
   - `requirements.txt`: 동작을 확인한 버전을 `==`로 고정한다. `pip freeze`로 확인할 수 있다.
   - `README.md`: 설치 방법, 실행 방법, 판정 기준, 한계를 적는다.
3. 가상환경(`.venv`)은 폴더마다 따로 만든다. 모델마다 라이브러리 버전이 달라도 서로 충돌하지 않는다.
4. 가중치와 데이터셋은 GitHub에 올리지 않는다. 자동 다운로드 코드를 넣거나 Google Drive로 공유하고, 받는 방법을 README에 적는다.
5. 위 폴더 표에 한 줄을 추가한다.

## 올리지 않는 파일

`.gitignore`에서 모든 폴더에 공통으로 제외한다.

- `.venv/` (가상환경)
- `models/`, `*.pt`, `*.pth`, `*.onnx` (가중치)
- `data/`, `sleep/` (데이터셋)
- `.env`, `*.key` (비밀 키)
