# mediapipe — 얼굴 랜드마크 규칙 졸음 감지

PC 웹캠이나 영상에서 얼굴을 보고, 눈 감음·하품·고개 끄덕임이 감지되면 화면 경고와 경고음을 낸다.
학습된 졸음 분류 모델은 쓰지 않는다. Google [mediapipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker)로 얼굴 랜드마크, 표정 점수(blendshape), 머리 자세를 구하고 규칙으로 판정한다.

## 설치

이 폴더 안에서 실행한다.

```bash
cd mediapipe
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

- Python 3.12, Windows 기준으로 확인했다.
- 라이브러리 버전은 `requirements.txt`에 `==`로 고정되어 있다. 동작을 확인한 버전이므로 임의로 올리지 않는다.
  - mediapipe는 `opencv-contrib-python`을 요구한다. 버전을 고정하지 않으면 OpenCV 5가 설치되므로 4.x로 고정했다.
- 모델 파일(`models/face_landmarker.task`, 약 4MB)은 처음 실행할 때 자동으로 다운로드된다. GitHub에는 올리지 않는다.

## 실행

```bash
python app.py                                    # 파일 선택 창에서 영상 선택, 취소하면 웹캠 실시간 감지. q로 종료
python test_videos.py ../sleep test_results.csv  # 폴더 안 mp4 전체를 화면 없이 판정해 CSV로 저장
```

## 판정 기준

매 프레임에서 얼굴 1개를 찾고, 아래 3가지 중 **하나라도** 해당하면 졸음으로 판정한다.

| 이유 | 기준 |
|---|---|
| `EYES` | 눈 감음 점수(`eyeBlinkLeft`·`eyeBlinkRight` 평균) > 0.5가 1초 이상 이어짐 |
| `YAWN` | 입 벌림 점수(`jawOpen`) > 0.5가 1초 이상 이어짐 |
| `NOD` | 고개 숙임 각도(pitch)가 최근 2초 중 가장 든 자세보다 15° 이상 큼 |

- 졸음이면 화면에 빨간 테두리, `DROWSY! WAKE UP` 문구, 이유를 띄우고 경고음을 1초에 한 번 울린다.
- 얼굴이 검출되지 않으면 기록을 비우므로 경고가 나지 않는다.
- 기준값은 `detector.py` 상단에서 바꾼다.

## 영상 테스트 결과 (2026-10-29)

데이터와 라벨, 다른 방식과의 비교는 [루트 README](../README.md#모델별-비교)를 본다. 영상별 결과는 [`test_results.csv`](test_results.csv)이고, `eyes`·`yawn`·`nod` 열은 이유별 첫 경고 시각(초)이다. 비어 있으면 그 이유로는 경고가 없었다.

| 항목 | 결과 |
|---|---|
| 졸음 감지 | 80 / 80 (100%), 첫 경고까지 평균 1.9초 |
| 오경보 | 50 / 80 (62%) — 음주운전 31/49, 물건찾기 19/30, 휴대폰조작 0/1 |
| 정확도 | 69% |
| 얼굴 검출 비율 (영상 평균) | 93% |

| 이유 | 졸음 감지 | 오경보 |
|---|---|---|
| `NOD` | 80 / 80 | 50 / 80 |
| `YAWN` | 11 / 80 | 0 / 80 |
| `EYES` | 0 / 80 | 0 / 80 |

- 경고는 사실상 `NOD`가 결정한다. 졸음 영상을 모두 잡지만, 음주운전(몸 못 가누기)과 물건찾기(허리 굽히기)에서도 고개가 크게 숙여져 오경보가 난다.
- `YAWN`은 오경보가 없지만 하품이 있는 영상에서만 잡힌다.
- `EYES`는 한 번도 경고하지 않았다. 고개를 숙이면 눈이 잘 보이지 않고, `eyeBlink` 점수가 0.5를 넘는 시간이 짧다.
- 기준값은 이 데이터의 일부 영상(운전자 SGA2100304 등)의 점수를 보고 정했다. 같은 데이터로 평가했으므로 실제 성능보다 좋게 나왔을 수 있다.
- 개선 후보(미적용): `NOD`는 짧은 시간 안에 여러 번 끄덕일 때만 경고하기, `EYES` 기준값 낮추기, 정상 운전 영상으로 오경보 측정하기.

## 한계

- 규칙 기반이라 졸음이 아닌데 고개를 숙이거나(물건 찾기, 계기판 보기) 입을 크게 벌리면(노래, 대화) 경고가 날 수 있다.
- 야간·어두운 조명, 선글라스·마스크·손 가림, 정면이 아닌 카메라 각도에서는 랜드마크 정확도가 떨어질 수 있다.
- CPU에서 영상 디코딩을 포함해 약 20ms/프레임이다.
